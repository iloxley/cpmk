# Support policy

CPMK 1.x is the supported line.

- Install the latest `1.x` release for fixes.
- Pre-1.0 tags such as `v0.4.0-m4.0` are unsupported.
- There is no separate LTS branch in 1.0.
- Schema version 1 memory and config files are the supported persisted format.
- Files under `.cpmk/generated/` can be deleted and regenerated.

Report vulnerabilities as described in `docs/SECURITY.md`.
