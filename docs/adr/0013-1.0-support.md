# ADR 0013: 1.0 support and generated-file surface

- Status: Accepted
- Date: 2026-08-17
- Deciders: Rob / iloxley

## Context

`docs/SECURITY.md` said only the newest pre-release is supported. Milestone 10 must replace that. Whether generated Markdown/JSON is a supported API was still open.

## Decision

- Version the CLI as `1.0.0`.
- Support the current 1.x release line. Pre-1.0 tags are unsupported.
- Treat `.cpmk/memory/*.json` and `.cpmk/config.json` as the supported persisted surface.
- Treat `.cpmk/generated/**` as disposable views.

The contract is `docs/contracts/M10_RELEASE.md`.

## Consequences

Users can rely on v1 memory files across 1.x. Regenerating handoff, context, cursor, and sync-conflict files is expected.

## Alternatives considered

An LTS promise would require a second maintained branch. Deferred until there is a 2.0.
